Порядок действий и точная цепочка команд (промптов) для Claude Code, чтобы развернуть Spec-Driven Development, написать код и запустить тесты.
Всё делается в терминале или прямо в чате Claude Code (UI/CLI) на macOS.
Шаг 1. Установка и инициализация (в терминале)
Убедись, что установлен Python 3.11+, менеджер uv и создан репозиторий. Выполни в корне проекта:
Bash
uv tool install specify-cli
specify init . --integration claude
Что произошло: В корне создались папка .specify/ (память, шаблоны) и папка .claude/skills/ со слэш-командами для Claude.
Шаг 2. Конституция проекта (в чате Claude)
Запусти Claude Code в папке проекта и вызови первый скилл. Напиши единым запросом рамки качества:
/speckit-constitution
Текст запроса: Создай принципы проекта (конституцию). Установи жесткие требования к чистоте архитектуры, обработке ошибок, обязательным юнит-тестам и чистому коду без дублирования.

Шаг 3. Создание спецификации (/speckit-specify)
Здесь ты описываешь что нужно сделать (бизнес-логика, UX, требования), не вдаваясь в технические детали.
/speckit-specify
Текст запроса: Создай спецификацию для [опиши свою задачу/фичу в 2-3 предложениях]. Сделай упор на пользовательские сценарии (User Stories) и критерии приёмки (Acceptance Criteria). Сохрани в specs/.

Claude сгенерирует файл spec.md. Проверь его, если нужно — подправь руками или попроси Claude исправить в чате.
Шаг 4. Проектирование плана и структур (/speckit-plan)
Когда спека утверждена, переводим её в техническую плоскость.
/speckit-plan
Текст запроса: На основе текущей спеки напиши детальный технический план (plan.md), выбери оптимальный стек, спроектируй модели данных и контракты/интерфейсы.

Claude создаст архитектурный план и схемы.
Шаг 5. Декомпозиция на задачи (/speckit-tasks)
Превращаем план в пошаговый чек-лист.
/speckit-tasks
Текст запроса: Разбей технический план на атомарные, упорядоченные по зависимостям задачи и запиши их в tasks.md.

Шаг 6. Изоляция контекста и запуск реализации (/speckit-implement)
Лайфхак из видео: Чтобы не захламлять контекст и сэкономить токены, очисти текущий чат (начни новый диалог с Claude), оставив файлы в репозитории, и вызови команду реализации:
/speckit-implement
Текст запроса: Прочитай файлы спеки, плана и чек-лист из tasks.md. Поочередно выполняй задачи из чек-листа, отмечай их выполненными и пиши код.

Claude начнет автономно создавать файлы, структуру и писать код по шагам.
Шаг 7. Сходимость и тестирование (/speckit-converge)
Когда Claude отчитается о выполнении задач, запускай финальный этап верификации и тестов.
/speckit-converge
Текст запроса: Проверь написанный код на соответствие исходной спеке, запусти сборку, линтеры и тесты. Убедись, что всё работает, или исправь обнаруженные баги до статуса Converged.
